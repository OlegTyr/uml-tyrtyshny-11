# Кандидаты в классы

| Существительное из сценария | Решение | Почему |
|---|---|---|
| набор тестов | класс `НаборТестов` | есть идентичность (два набора с одинаковым названием — разные), жизненный цикл, собственное поведение (список тестов) |
| тест | класс `Тест` | отдельная единица с идентичностью и историей; не атрибут набора, т.к. у теста есть флаг «флаки» и своя история результатов |
| прогон | класс `Прогон` | отдельный объект со статусом и датами; идентифицируется по UUID |
| результат теста | класс `РезультатТеста` | принадлежит паре (прогон, тест), имеет собственные атрибуты (статус, длительность, лог) |
| runner-агент | класс `RunnerАгент` | есть состояние (свободен/занят/офлайн) и идентификатор |
| статус прогона | enum `СтатусПрогона` | перечисление, нет идентичности и поведения |
| статус теста | enum `СтатусТеста` | перечисление |
| статус агента | enum `СтатусАгента` | перечисление |
| флаг флаки | атрибут `Тест.флаки : boolean` | производное от истории, но хранится как флаг; нет собственного жизненного цикла |
| длительность | атрибут `РезультатТеста.длительность : int` | производное значение, не объект |
| лог | атрибут `РезультатТеста.лог : String` | текст, не имеет поведения |
| история прогонов | класс `ИсторияПрогонов` (сервис) | не сущность предметной области, а сервис чтения; вынесен отдельно, чтобы не смешивать с `Прогон` |
| уведомление | не моделируем | артефакт внешней системы, вне границы |
| права | атрибут роли / проверка в сервисе | не класс предметной области |
| расписание | класс `Расписание` | имеет собственный жизненный цикл (cron-выражение, активность), не атрибут набора |
| порог доли падений | атрибут `ПолитикаФлаки.порог` | параметр правила |
| минимальное число прогонов K | атрибут `ПолитикаФлаки.минПрогонов` | параметр правила |
| политика флаки | класс `ПолитикаФлаки` | правило меняется, зависит от истории; вынесено из `Тест`, чтобы не раздувать его |
| проект | класс `Проект` | группирует наборы; нужен для агрегации (набор может пережить проект) |
