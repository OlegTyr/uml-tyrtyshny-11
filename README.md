## О системе

Система автоматического тестирования предназначена для запуска наборов тестов по запросу разработчика и по триггеру из CI. Основные пользователи: разработчик (запускает тесты, смотрит отчёты, разбирается с падениями), CI-система (внешний актёр, запускает тесты на каждый коммит) и администратор (настраивает окружение, управляет наборами, размечает флаки-тесты).

Система хранит историю прогонов, помечает нестабильные тесты как флаки, формирует отчёты и отправляет уведомления во внешнюю систему (Slack/почта). Ключевая задача — дать быструю и достоверную обратную связь о качестве сборки.
